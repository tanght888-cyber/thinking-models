# 思维模型参谋 (Thinking Models)

108个人类顶级思维模型的决策辅助工具。专为需要做战略规划、商业分析、产品设计、组织管理、个人成长等重大决策的场景而设计。

## 功能特性

- **智能推荐**：根据用户描述的场景，自动推荐最合适的思维模型
- **详细讲解**：每个模型都有核心逻辑、应用步骤、注意事项
- **场景覆盖**：战略、营销、产品、组织、个人成长等全链路
- **快速索引**：11大分类、108个模型，一目了然

## 适用人群

- 创业者和管理者
- 产品经理和战略规划者
- 需要系统性思考框架的职场人士
- 希望提升决策质量的任何人

## 使用方式

当你在做决策或规划时，直接描述你的场景，例如：

- "我要做一个新产品的市场进入策略"
- "团队沟通有问题怎么办"
- "如何制定季度目标"

系统会自动推荐适合的思维模型并给出详细应用指导。

## 安装使用

本项目为 Claude Code 的 Skills 插件。

1. 克隆本仓库到本地
2. 将 `thinking-models` 目录复制到你的 Claude Code skills 目录下
3. 在 Claude Code 中即可使用
